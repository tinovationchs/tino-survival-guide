# 🚀 How to Contribute using GitHub Codespaces (No Downloads Required!)

Don't want to download any coding software? No problem! You can edit the code directly in your browser using **GitHub Codespaces**.

### Step 1: Spin up your Workspace
1. Go to the main page of the `tino-survival-guide` repository.
2. Click the green **`<> Code`** button.
3. Switch to the **Codespaces** tab.
4. Click the green **Create codespace on main** button.
*(Wait a minute or two while it sets up your personalized cloud computer!)*

### Step 2: Create Your Own Branch
We never edit the `main` code directly! You need your own workspace branch.
1. Look at the very bottom-left corner of the screen. You should see a button that says `main`.
2. Click `main`, and a menu will pop up at the top of the screen.
3. Select **`+ Create new branch`**.
4. Name it something related to your task (e.g., `feature/johns-advice` or `add-boba-tier`). Press **Enter**.

### Step 3: Write Your Code!
1. Use the file explorer on the left sidebar to find the file you need to edit (for example, `script.js` or `data/lore.json`).
2. Add your advice, unwritten rule, or food spot following the templates provided.

### Step 4: See Your Changes Live (Optional but Cool)
Want to see what your code looks like on the actual website?
1. Click the **Extensions** icon on the far left sidebar (it looks like 4 blocks).
2. Search for **Live Preview** (by Microsoft) and click Install.
3. Go back to your files, right-click on `index.html`, and select **Show Preview**. A mini-browser will open right inside Codespaces showing the live site!

### Step 5: Save & Submit (The Git Workflow)
1. Click the **Source Control** icon on the far left sidebar (it looks like a branch with a circle).
2. You will see a list of the files you changed. Hover over the word "Changes" and click the **`+`** icon to "stage" them.
3. Type a short message in the text box explaining what you did (e.g., "Added my survival advice").
4. Click the blue **Commit** button.
5. Finally, click **Publish Branch** (or Sync Changes).

### Step 6: Open Your Pull Request!
1. Go back to the main GitHub page for the repository.
2. You will see a bright green button at the top that says **Compare & pull request**. Click it!
3. Leave a comment tagging the maintainer (e.g., "Hey, I added my advice, ready for review!") and click **Create pull request**.
